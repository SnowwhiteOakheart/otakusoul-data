# Kaguya Shinomiya – Charakter-Preset

Neu generierter Avatar (`kaguya_shinomiya.png`, 700×937 PNG mit eingebetteter V2-Definition) und sechs passende Expressions (640×800 WebP) unter `expressions/`: neutral, happy, relaxed, surprised, angry, sad.

Der Avatar entstand ausschließlich aus Text; die Expressions verwenden nur diesen neuen Avatar als Referenz. Die Charakterdefinition bleibt bis auf die Bildzuordnung erhalten.

Zur lokalen Nutzung die Karte importieren und die WebP-Dateien im lokalen Expressions-Verzeichnis unter `expressions/kaguya-shinomiya/` bereitstellen.
