# Lucy (Elfen Lied) – Charakter-Preset

Neu generierter Avatar (`lucy.png`, 700×937 PNG mit eingebetteter V2-Definition) und sechs passende Expressions (640×800 WebP) unter `expressions/lucy/`: `neutral`, `happy`, `relaxed`, `surprised`, `angry`, `sad`.

Der Avatar entstand als Textgenerierung über das eingebaute `image_gen`-Werkzeug; die sechs Expressions verwenden den generierten Avatar als direkte Identitäts- und Kompositionsreferenz.

Vollständige V2-Charakterdefinition mit dualer Persönlichkeit (Lucy / Nyu / Kaede), Vektor-Mechanik, atmosphärischem Einstiegsszenario am Strand von Kamakura und dreisprachiger Unterstützung (DE, EN, RU).

Zur lokalen Nutzung die Karte importieren und die WebP-Dateien im lokalen Expressions-Verzeichnis unter `expressions/lucy/` bereitstellen.
